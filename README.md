# KNN-Classifier
A KNN Classifier (K-Nearest Neighbors Classifier) is a supervised machine learning algorithm used for classification problems.  It predicts the class of a new data point based on the classes of its nearest neighbors.
Implemented the Machine Learning K-Nearest Neighbors (KNN) classification algorithm using Python and visualized its decision boundaries on synthetic 2D data. The project demonstrates how KNN classifies data points based on the majority class of their nearest neighbors using different values of K and distance metrics.

Key Features
Implemented KNN classification using scikit-learn
Generated synthetic datasets for testing
Visualized decision boundaries using Matplotlib
Compared model behavior for different K values
Explored distance metrics such as Euclidean and Minkowski distance
Concepts Covered
Supervised Learning
Distance-based Classification
Decision Boundary Visualization
Mesh Grid Prediction
Model Performance Analysis
Technologies Used
Python
NumPy
Matplotlib
Scikit-learn

This project helped in understanding how KNN works internally, how distance metrics influence classification, and how decision boundaries change with different neighbor values.
